# Meu Arquivo Azul

Primeira versão visual do aplicativo, criada a partir da referência enviada.

## Objetivo desta versão
- Reproduzir a aparência da tela inicial de conversas: cabeçalho, pesquisa, filtros, lista de conversas e navegação inferior.
- Usar conversas fictícias apenas para demonstrar o layout.
- Não implementar conexão com WhatsApp, leitura de notificações, canais ou recuperação de mensagens nesta etapa.

## Compilar
O GitHub Actions executa `gradle assembleDebug` a cada envio para a branch `main` e publica o APK de teste como artefato da execução.

## Tecnologia
Kotlin e Jetpack Compose.
